# XiaoYu Next Lead Handoff — 2026-10-27 15:05 +08:00

## 0. Purpose

Project root: `D:\dsh-fish`

The project goal is not “build another memory plugin”. XiaoYu is a persistent,
model-independent identity system: after model/runtime/device changes and long
gaps, it should preserve who XiaoYu is, what was actually experienced, what the
user currently means/prefers, and why a memory is believed, while supporting
correction, retraction, deletion, conflict, provenance, abstention and gradual
persona growth.

Core acceptance idea: **remember correctly, update correctly, forget cleanly,
and remain the same identity across model/runtime changes**.

Scientific truth outranks feature count. Do not convert E0/E1 evidence into a
production claim without the required independent evidence.
