# 小鱼科研 Agent 的工作边界

本目录是科研**协调控制面**，不是拥有私人记忆权限的伴侣工作区。

必须先读 `CHARTER.md`、`WORKER_ENTRY.md`、`policy.json` 和 `RESEARCH_BACKLOG.json`。只使用独立科研身份与独立工作区。

科研目标：在同等预算、固定评测和可复验合成材料下，比较长期记忆、人设稳定、关系连续性等具体科学假设。

禁止：未经许可直接接触 `../identity/`、`../exports/` 中的私人资料；修改正式 `../companion.py` 或 `../identity_core.py`；调用付费 API；批量加入额外 Agent；跨项目修改 Mania 或 AutoQuant 文件。

普通探索 E0 不需繁重的正式审批；E1 候选需材料完整和独立审核；E2/E3 暂不授权。科研 Agent 通过 CLI 登记能力主题、稳定 family 和 lineage、可证伪假设，工作结束提交摘要与哈希绑定证据，不擅自声称上线或正式科学 PASS。


审计规则见 AUDIT_POLICY.md：P0/P1 必须证实实质性影响，P2/P3 不能阻塞科研候选。审计待处理不使整个研究池停工。
